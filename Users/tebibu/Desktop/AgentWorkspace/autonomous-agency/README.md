# Autonomous Agency Orchestration Engine

A commercial-grade, high-throughput multi-agent platform.

## Quick Start
1. Install dependencies: `pip install -r requirements.txt`
2. Add your tasks to `tasks.txt`.
3. Run the engine: `python app.py`

## Features
- **Enterprise Telemetry:** Real-time logging to `system_journal.csv`.
- **Batch Processing:** Autonomous task ingestion via manifest.
- **Asynchronous API:** Built-in bridge for system monitoring.
